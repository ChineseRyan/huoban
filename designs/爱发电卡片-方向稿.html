二维码来自开发者 2026-11-14 提供的爱发电官方卡片：取原图 37×37 模组逐格重排（模组 10px）， 与原图逐模组比对零差异，OpenCV 解码结果与原图一致—— https://afdian.com/u/e36080ca51d411e9900752540025c377?utm_source=qrpic&utm_medium=link。 白牌四周留 5 模组静区。

落地时还有一处实现取舍待你定：卡片做成两张调好色的 PNG（浅/深各一），还是「二维码白牌 PNG + 卡片用 CSS 画」—— 后者颜色直接吃 CSS 变量、不会出现图片色差，但 assets 里只放二维码本体。
