三稿共同的落地条件

1. 打赏审核通过前一律 disabled + aria-disabled、无 href、无 hover、低对比描边 + var(--ink-3) 字；配色全走 CSS 变量，不写死色值。

2. 只拦两条链接与按钮的点击，不拦整个页脚 —— 否则页脚空白处点不回首页，违背 gui/ui.html:3986「整页都算空白处」。外链须 preventDefault() + stopPropagation() 并经 js_api 打开系统浏览器；目前 gui/api.py:2412-2433 只有 os.startfile，该通道待新增。

3. 待你确认：小红书主页链接及「首页」是否指个人主页；GitHub 项目页正式 URL（现只有 README.md:42 的 clone 地址）；爱充电审核结果；旧口径 docs/gui-design.md:131-134 与 gui/ui.html:3982-3986 是否明确作废。

4. 措辞冲突按结句执行：「请喝杯茶」放右下角，与左侧两入口拉开；若其实想放最左侧，说一句就翻过来。

5. 本文件为设计稿预览；未修改 gui/ui.html、gui/api.py 及任何源码与文档。
